# PRIVACY POLICY — QUANTUM Leaps
## Last updated: 15 June 2026

### 1. Data yang Dikumpulkan
Kami hanya mengumpulkan data yang diperlukan untuk memberikan layanan:
- **Alamat email** — untuk autentikasi dan notifikasi akses premium
- **Riwayat kalkulasi** — untuk keperluan teknis dan perbaikan layanan
- **Data pembayaran** — diproses oleh Pakasir (kami tidak menyimpan data kartu/rekening)

### 2. Penggunaan Data
Data Anda digunakan untuk:
- Verifikasi akses premium
- Pengiriman notifikasi terkait layanan (update fitur, maintenance)
- Analisis internal untuk meningkatkan kualitas layanan

### 3. Penyimpanan Data
- Data disimpan di Supabase (infrastruktur cloud, security compliance SOC2).
- Riwayat kalkulasi Anda tetap tersimpan selama akun aktif.
- Data pembayaran dikelola sepenuhnya oleh Pakasir.

### 4. Hak Anda (UU PDP)
Berdasarkan Undang-Undang Perlindungan Data Pribadi Indonesia, Anda berhak untuk:
- **Mengakses** data pribadi yang kami simpan
- **Memperbaiki** data yang tidak akurat
- **Menghapus** data Anda (hak untuk dilupakan) — kirim request ke email di bawah
- **Menarik persetujuan** penggunaan data
- **Mengajukan keberatan** atas pemrosesan data

### 5. Retensi Data
Data akun akan kami simpan selama akun aktif. Jika akun tidak aktif selama 2 tahun, data dapat kami hapus setelah pemberitahuan.

### 6. Keamanan
- Koneksi dienkripsi via HTTPS/SSL.
- Kami tidak pernah membagikan data pribadi Anda ke pihak ketiga, kecuali diwajibkan hukum.
- Token JWT auth dikelola oleh Supabase Auth.

### 7. Cookie
Layanan ini menggunakan local storage untuk token sesi auth (no third-party cookies).

### 8. Perubahan Kebijakan
Perubahan privacy policy akan diumumkan melalui email atau halaman ini.
